# 算法术语表

| 术语 | 通俗解释 |
| --- | --- |
| 算法 | 为了解决某类问题而规定的一组有限步骤 |
| 数据结构 | 数据在内存中的组织方式，以及允许进行的操作 |
| 输入规模 `n` | 用来描述问题有多大的数字，例如数组长度 |
| 时间复杂度 | 输入变大时，主要操作次数增长得有多快 |
| 空间复杂度 | 输入变大时，额外内存需求增长得有多快 |
| 原地算法 | 只使用少量额外空间，主要在原数据上操作 |
| 稳定排序 | 相等元素在排序后的相对顺序不变 |
| 递归 | 函数通过更小的问题调用自己 |
| 迭代 | 使用循环重复执行步骤 |
| 状态 | 描述算法当前所处情况所需的信息 |
| 不变量 | 算法执行过程中始终成立的事实 |
| 边界 | 数据或搜索范围的起点、终点以及是否包含端点 |
| 哨兵 | 为简化边界判断而设置的特殊元素或位置 |
| 哈希 | 把键转换成存储位置或数字指纹的方法 |
| 冲突 | 不同键得到相同哈希位置 |
| DFS | 深度优先搜索，沿一条路尽量走到底再返回 |
| BFS | 广度优先搜索，一层一层向外探索 |
| 回溯 | 做选择、继续搜索、撤销选择并尝试下一种可能 |
| 剪枝 | 提前确定某条搜索分支不可能成功，从而不再探索 |
| 贪心 | 每一步选择当前最合适的方案，并证明它不会破坏全局最优 |
| 动态规划 | 保存重复子问题的答案，再组合成更大问题的答案 |
| 状态转移 | 当前状态怎样从较小或较早的状态得到 |
| 图 | 由节点和节点之间的连接组成的数据结构 |
| 连通 | 两个节点之间存在一条可以到达的路径 |
| 拓扑排序 | 对有向无环图排序，使每个前置任务出现在后续任务之前 |
| 摊还分析 | 把偶尔很贵的操作分摊到一系列操作中评价平均成本 |
| NP-complete | 一类彼此可归约、目前不知道多项式时间通用解法的困难问题 |

术语表会随着知识库扩展继续补充。遇到陌生词时，先理解它在解决什么问题，不必急着背正式定义。
