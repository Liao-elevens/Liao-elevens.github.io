# 算法学习路线

这条路线不规定一天学多少，也不规定几周学完。唯一的顺序依据是：**后面的知识是否依赖前面的知识**。

## 主线一：能够读写算法

你需要先掌握这些共同概念：

1. 变量保存状态；
2. 条件决定分支；
3. 循环处理重复工作；
4. 函数封装步骤；
5. 数组保存一组有顺序的数据；
6. 字符串是一组字符；
7. 下标、长度、空数据和边界；
8. 四种语言中容器和类型的对应关系。

完成标准不是背住语法，而是能用四种语言完成：

- 遍历数组并求和；
- 找出最大值和它的位置；
- 统计元素出现次数；
- 反转字符串；
- 按行列遍历矩阵。

## 主线二：学会评价一个解法

在接触复杂算法之前，先理解：

- 输入规模是什么；
- 一条语句大致执行多少次；
- 为什么两层完整循环通常是 `O(n²)`；
- 为什么二分查找是 `O(log n)`；
- 为什么哈希表能用额外空间换查询速度；
- 为什么递归除了运行时间还要考虑栈空间。

## 主线三：掌握数据的组织方式

| 顺序 | 数据结构 | 关键问题 |
| --- | --- | --- |
| 1 | 数组与字符串 | 如何按位置保存和访问数据 |
| 2 | 哈希表与集合 | 如何快速计数、去重和判断存在 |
| 3 | 栈与队列 | 如何表达后进先出和先进先出 |
| 4 | 链表 | 不连续的数据如何连接 |
| 5 | 树 | 如何表达层级和递归结构 |
| 6 | 堆 | 如何快速取得最大或最小元素 |
| 7 | 图 | 如何表达任意连接关系 |

## 主线四：形成题型识别能力

| 看到的信号 | 优先想到 |
| --- | --- |
| 有序数组、临界值、单调答案 | 二分查找 |
| 两端向中间、成对关系 | 左右双指针 |
| 同方向移动、删除重复 | 快慢指针 |
| 连续子数组或子字符串 | 滑动窗口、前缀和 |
| 多次查询区间和 | 前缀和 |
| 多次修改连续区间 | 差分 |
| 最近更大或更小元素 | 单调栈 |
| 窗口最大值或最小值 | 单调队列 |
| 所有组合、排列或路径 | 回溯 |
| 层数最少、无权最短路 | BFS |
| 层级、子树、连通性 | DFS |
| 当前选择影响后续但可证明安全 | 贪心 |
| 重复子问题与最优子结构 | 动态规划 |

## 统一学习闭环

每个知识点都用同一套流程：

| 步骤 | 必须回答的问题 |
| --- | --- |
| 复述问题 | 输入、输出、限制和目标分别是什么 |
| 手工模拟 | 一个最小例子是怎样一步步得到答案的 |
| 暴力方案 | 不考虑效率时最直观的方法是什么 |
| 找到瓶颈 | 哪一步重复最多、最浪费时间或空间 |
| 提炼算法 | 哪种数据结构或规律可以消除浪费 |
| 写伪代码 | 如果不考虑语言语法，需要执行哪些动作 |
| 四语言实现 | 容器、类型、比较器和边界分别怎样表达 |
| 验证 | 空数据、单元素、重复值、极端值是否正确 |
| 复盘 | 没想到的信号是什么，下次如何识别 |

## 四语言学习原则

```text
问题
  ↓
语言无关的算法思想
  ↓
统一伪代码
  ├── Java：重视类型、接口与标准容器
  ├── Python：重视简洁表达与隐藏复杂度
  ├── JavaScript：重视 Number、比较器与运行环境
  └── C++：重视 STL、值/引用和整数范围
```

不要尝试记住四份互不相关的模板。每当四种代码看起来差别很大时，回到伪代码，找到它们共同表达的步骤。

## 进入下一阶段的判断方式

你不需要“全部熟练”才继续，但至少应该做到：

- 能用自己的话解释核心概念；
- 能手工模拟一个小例子；
- 能写出暴力解法；
- 知道标准解法为什么更快；
- 能看懂四种语言版本；
- 隔开答案后，至少能独立写出自己最熟悉语言的版本。
