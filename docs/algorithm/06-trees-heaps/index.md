# 树与堆

树把复杂问题拆成多个互不重叠的子树，是递归思想最自然的载体。

## 树的完整地图

| 层级 | 主题 |
| --- | --- |
| L1 | 二叉树节点、前中后序、层序遍历 |
| L1 | 高度、深度、节点数、路径、直径 |
| L2 | 二叉搜索树、插入、查找、删除 |
| L2 | 堆、优先队列、Top K、堆排序 |
| L2 | LCA、树上倍增、欧拉序 |
| L3 | AVL、红黑树、Treap、Splay |
| L3 | B 树、B+ 树、磁盘索引 |
| L3 | 树链剖分、点分治、重心 |
| L4 | 动态树、虚树、树哈希、DSU on Tree |

## 遍历决定信息流动方向

- 前序：先处理当前节点，再处理孩子；
- 中序：在左右子树之间处理当前节点；
- 后序：先收集孩子的信息，再计算当前节点；
- 层序：按照距离根节点的层数处理。

很多树题的关键问题其实是：信息应该从父亲传给孩子，还是从孩子汇总给父亲？
