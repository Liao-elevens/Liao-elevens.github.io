# 图论

当关系不再是“一条线”或“一棵树”，图就是最通用的表达：地点和道路、用户和关注、课程和依赖都可以建模为图。

## 图论知识树

| 领域 | 核心算法 |
| --- | --- |
| 表示与遍历 | 邻接表、邻接矩阵、DFS、BFS |
| 有向无环图 | 拓扑排序、关键路径、环检测 |
| 连通性 | 连通分量、并查集、强连通分量 |
| 无权路径 | BFS、双向 BFS |
| 加权最短路 | Dijkstra、Bellman–Ford、Floyd、Johnson |
| 生成树 | Prim、Kruskal、次小生成树 |
| 图的结构 | 割点、桥、双连通分量、欧拉路径 |
| 匹配 | 二分图匹配、匈牙利、Hopcroft–Karp |
| 网络流 | 最大流、最小割、费用流 |
| 逻辑建模 | 2-SAT、差分约束 |

## 建图比套算法更重要

现实问题通常不会直接说“这是图”。先确定：

1. 什么是节点；
2. 什么是边；
3. 边有没有方向；
4. 边有没有权重；
5. 需要回答可达、最短、连通还是选择问题。
