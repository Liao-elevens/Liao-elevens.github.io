# 贪心算法

贪心不是“每一步随便挑看起来最好的”。一个贪心算法必须说明：当前选择为什么可以保留在某个全局最优解中。

## 典型模型

- 活动选择与区间调度；
- 区间覆盖、区间分组；
- 最小延迟和任务排序；
- Huffman 编码与最优合并；
- 最小生成树；
- 找零与硬币系统；
- 跳跃、加油和资源分配；
- 拟阵上的贪心；
- 集合覆盖等问题的近似贪心。

## 常见证明方法

| 方法 | 思路 |
| --- | --- |
| 交换论证 | 把某个最优解的第一步换成贪心选择，答案不会更差 |
| 领先法 | 证明贪心方案在每个阶段都不落后 |
| 归纳法 | 做出贪心选择后，剩余问题仍是同类子问题 |
| 反证法 | 假设贪心选择不在最优解中，推出矛盾 |

## 反例意识

看到“当前最大”“当前最小”时，不要立即使用贪心。先尝试构造一个小反例，检查局部选择是否会让未来失去更好的组合。
