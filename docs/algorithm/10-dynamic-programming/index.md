# 动态规划

动态规划把一个问题拆成相互重叠的子问题，保存子问题答案，再按照依赖顺序组合结果。

## 五个固定问题

| 问题 | 作用 |
| --- | --- |
| 状态表示什么 | 给 `dp[i]` 或 `dp[i][j]` 一个完整句子定义 |
| 当前有哪些选择 | 哪些操作会产生不同后续状态 |
| 怎样转移 | 当前状态依赖哪些更小状态 |
| 初始状态是什么 | 最小问题的答案如何直接确定 |
| 按什么顺序计算 | 保证依赖状态已经得到答案 |

## 完整目录

| 层级 | 类型 |
| --- | --- |
| L1 | 记忆化搜索、递推、爬楼梯、网格路径 |
| L1 | 0/1 背包、完全背包 |
| L2 | LIS、LCS、编辑距离 |
| L2 | 区间 DP、树形 DP |
| L2 | 状态压缩 DP、数位 DP |
| L3 | 多重背包、分组背包、依赖背包 |
| L3 | 概率 DP、期望 DP、博弈 DP |
| L4 | 单调队列优化、斜率优化、分治优化 |
| L4 | 四边形不等式、插头 DP |

## 一个判断信号

如果递归搜索中，不同路径反复到达同一个“剩余问题”，就应该考虑记忆化；如果这些状态之间存在明确顺序，就可以进一步改写为递推。
