# 复杂度、正确性与分析

算法分析回答三个问题：

1. 它能不能得到正确答案？
2. 数据变大时，它会慢到什么程度？
3. 它需要多少额外空间？

## 知识目录

| 层级 | 主题 |
| --- | --- |
| L1 | 输入规模、基本操作、Big O、常见增长速度 |
| L1 | 最好、平均、最坏情况 |

## 一个直觉

在电话簿里找名字：

- 从第一页逐行找，数据翻倍时工作量大致翻倍，属于 `O(n)`；
- 如果电话簿有序，每次翻到中间并排除一半，属于 `O(log n)`；
- 先建立“姓名到页码”的索引，查询可以接近 `O(1)`，但要付出额外空间。

这体现了算法分析最常见的权衡：**预处理、查询速度和空间不能同时免费。**
