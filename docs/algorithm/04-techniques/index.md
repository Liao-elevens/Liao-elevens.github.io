# 高频算法技巧

这些技巧不是孤立的数据结构，而是反复出现的“减少重复工作”方式。

## 技巧地图

| 技巧 | 识别信号 | 消除的浪费 |
| --- | --- | --- |
| 左右双指针 | 有序、两端、配对 | 不再枚举所有二元组 |
| 快慢指针 | 原地覆盖、环、链表 | 不需要额外数组或重复扫描 |
| 滑动窗口 | 连续区间、条件可维护 | 不重新计算整个区间 |
| 前缀和 | 多次区间求和 | 每次查询不再遍历区间 |
| 差分 | 多次区间修改 | 每次更新不再修改所有元素 |
| 单调栈 | 最近更大或更小 | 不向两侧反复搜索 |
| 单调队列 | 滑动窗口极值 | 不重新寻找窗口最大最小值 |
| 离散化 | 值很大但数量有限 | 压缩无用数值空间 |
| 扫描线 | 区间、几何事件 | 把二维或区间关系按顺序处理 |
| 离线处理 | 查询可以重新排序 | 利用全局顺序共享工作 |
