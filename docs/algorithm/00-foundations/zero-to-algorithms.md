# 算法到底是什么：零基础第一课

如果你刚开始学 Java、Python、JavaScript 和 C++，看到“复杂度、递归、动态规划”这些词可能会紧张。先把它们放到一边。算法最开始只是一件很朴素的事：

> **把解决问题的步骤，说得足够明确，让人或计算机每次都能照着做。**

这篇不要求你会写完整程序。读完后，你只需要能认出一个问题的输入、输出、步骤和状态。

## 从泡一杯茶开始

“泡茶”不是一个可以直接交给计算机执行的算法，因为它太模糊：

- 用多少水？
- 水温多少？
- 茶叶放多少？
- 泡多久？
- 没有水怎么办？

把它改写得明确一些：

```text
输入：一只杯子、5 克茶叶、300 毫升水

1. 如果水少于 300 毫升，报告“水不够”并停止
2. 把水加热到 90℃
3. 把茶叶放入杯中
4. 倒入 300 毫升热水
5. 等待 180 秒
6. 输出一杯茶
```

这已经具备了算法的基本组成：

| 组成 | 泡茶例子 | 编程中的含义 |
| --- | --- | --- |
| 输入 | 水、茶叶、杯子 | 程序收到的数据 |
| 输出 | 一杯茶或错误提示 | 程序返回的结果 |
| 步骤 | 加热、倒水、等待 | 按顺序执行的语句 |
| 条件 | 水够不够 | `if / else` 分支 |
| 状态 | 当前水温、已等待时间 | 变量中不断变化的数据 |
| 结束条件 | 等待满 180 秒 | 循环何时停止 |

## 程序为什么需要变量

变量可以理解为带名字的小盒子。盒子里放着程序当前记住的信息。

假设要统计购物车总价：

```text
商品价格：12、8、20
```

我们准备一个叫 `total` 的盒子：

```text
开始：total = 0
读到 12：total = 0 + 12 = 12
读到 8： total = 12 + 8 = 20
读到 20：total = 20 + 20 = 40
结束：返回 total
```

`total` 就是算法的**状态**。它不是永远不变的答案，而是“截至当前为止”的结果。

::: tip 初学者最重要的阅读问题
看到一个变量时，不要只问“它是什么类型”，还要问：

1. 它表示什么现实含义？
2. 它什么时候第一次获得值？
3. 哪些语句会改变它？
4. 循环每走一步后，它应该满足什么条件？
:::

## 条件：让程序选择不同道路

生活中的规则经常带有“如果”：

```text
如果温度低于 10℃，穿外套；
否则，不穿外套。
```

五种语言只是写法不同，思想完全一样：

::: code-group

```java [Java]
if (temperature < 10) {
    System.out.println("穿外套");
} else {
    System.out.println("不用穿外套");
}
```

```python [Python]
if temperature < 10:
    print("穿外套")
else:
    print("不用穿外套")
```

```javascript [JavaScript]
if (temperature < 10) {
  console.log('穿外套')
} else {
  console.log('不用穿外套')
}
```

```cpp [C++]
if (temperature < 10) {
    std::cout << "穿外套\n";
} else {
    std::cout << "不用穿外套\n";
}
```

```go [Go]
if temperature < 10 {
	fmt.Println("穿外套")
} else {
	fmt.Println("不用穿外套")
}
```

:::

需要先记住的不是括号，而是：

```text
条件为真  → 执行第一条道路
条件为假  → 执行另一条道路
```

## 循环：让重复工作只写一次

如果要打印五位同学的成绩，可以写五次打印语句。但如果有一万位同学，就需要循环。

```text
准备一个位置 index = 0

只要 index 还没有超过最后一个位置：
    打印当前位置的成绩
    index 向后移动一格
```

一个循环必须想清楚三件事：

| 问题 | 示例 |
| --- | --- |
| 从哪里开始 | `index = 0` |
| 什么时候继续 | `index < scores.length` |
| 每轮怎样接近结束 | `index = index + 1` |

如果第三项没有让循环更接近结束，程序就可能进入死循环。

## 数组：一排有编号的盒子

数组可以想成一排储物柜：

```text
下标      0    1    2    3
数据     12    8   20    6
```

下标通常从 `0` 开始。因此：

- 第一个元素的下标是 `0`；
- 最后一个元素的下标是 `长度 - 1`；
- 长度为 `4` 时，合法下标是 `0、1、2、3`；
- 访问下标 `4` 会越界。

“数组长度”和“最后一个下标”差 `1`，这是大量初学错误的来源。

## 第一个完整算法：找到最大值

问题：

```text
输入：[7, 2, 9, 4]
输出：9
```

### 人是怎么做的

拿第一个数 `7` 当作暂时最大值：

| 当前看到的数 | 原来的最大值 | 比较结果 | 新的最大值 |
| --- | ---: | --- | ---: |
| 7 | 暂无 | 第一个数 | 7 |
| 2 | 7 | 2 没有更大 | 7 |
| 9 | 7 | 9 更大 | 9 |
| 4 | 9 | 4 没有更大 | 9 |

### 语言无关伪代码

```text
如果数组为空：
    报告没有最大值

maximum = 第一个元素

从第二个元素开始逐个查看：
    如果当前元素 > maximum：
        maximum = 当前元素

返回 maximum
```

这里最重要的不是记代码，而是理解一句话：

> 每轮循环结束后，`maximum` 都是“已经看过的所有元素”中的最大值。

这句话叫作循环不变量。它是判断算法是否正确的重要工具。

## 算法、数据结构和编程语言的关系

```text
问题：从联系人中快速找到“小明”
  ↓
数据结构：怎样组织联系人
  ↓
算法：按照什么步骤查找
  ↓
编程语言：用哪种语法告诉计算机
```

可以把它们类比成搬家：

- **数据结构**是纸箱、抽屉和标签的组织方式；
- **算法**是打包、编号、运输和拆箱的步骤；
- **编程语言**是你用来写搬家说明书的语言。

Java、Python、JavaScript、C++、Go 不会改变二分查找的核心思想，只会改变数组类型、循环写法和函数声明。

## 正确答案不一定是好算法

要在一摞有序号码中找出 `73`：

- 从头逐个看，一定能找到；
- 每次查看中间位置，也能找到；
- 第二种方法通常更快。

因此评价算法至少看三件事：

| 维度 | 问题 |
| --- | --- |
| 正确性 | 所有合法输入都能得到正确结果吗 |
| 时间 | 输入变大时，需要执行多少工作 |
| 空间 | 除了输入，还需要多少额外存储 |

现在不必计算 Big O，只要先养成一个意识：**能运行只是起点，不是终点。**

## 学算法时不要同时做五份工作

你正在同步学五种语言，推荐按下面的顺序：

1. 用自然语言解释问题；
2. 用纸笔模拟最小例子；
3. 写语言无关的伪代码；
4. 先用最熟悉的一种语言实现；
5. 再对照另外四种语言；
6. 比较容器、类型、函数和边界的差异。

不要一开始就要求自己凭空写出五份代码。你的目标是掌握一个算法思想，再学习五种表达。
