# 编程与数学前置

算法入门不要求先学完整个计算机专业，但需要一组共同语言。这里负责把四种编程语言不同的语法，映射到相同的计算概念。

## 编程基础目录

| 模块 | 必须理解 | 典型任务 |
| --- | --- | --- |
| 变量与类型 | 值如何保存、类型限制什么操作 | 交换两个数字 |
| 条件 | 根据真假选择执行路径 | 判断奇偶和大小 |
| 循环 | 重复处理一组数据 | 数组求和 |
| 函数 | 参数、返回值、作用域 | 封装最大值查找 |
| 数组与字符串 | 下标、长度、修改与遍历 | 统计字符 |
| 二维数组 | 行列和方向 | 遍历棋盘 |
| 引用与复制 | 修改是否影响原数据 | 函数中修改数组 |
| 整数与精度 | 溢出、浮点误差、大整数 | 大数求和 |
| 位运算 | 二进制状态与掩码 | 判断某一位 |
| 调用栈 | 函数调用如何保存现场 | 理解递归 |

## 数学基础目录

- 集合、交集、并集、差集；
- 命题、充分条件、必要条件；
- 求和、等差与等比数列；
- 指数与对数；
- 排列、组合、容斥；
- 概率、期望与独立事件；
- 数学归纳法、反证法；
- 向量、矩阵和基础几何。

::: info 学习标准
不要求先证明复杂定理。你只需要能在算法出现这些符号时读懂它们，并通过实例解释含义。
:::

## 四语言共同模型

```text
读取输入 → 保存状态 → 判断条件 → 重复执行 → 返回结果
```

语言只是给这五类动作提供不同的语法。先阅读：[四语言算法基础 →](./four-language-basics)
