# 排序、选择与查找

排序的价值不只是“把数字排好”。顺序会暴露规律，让查找、去重、区间处理和贪心选择变得简单。

## 排序全景

| 类型 | 算法 | 典型复杂度 | 关键特点 |
| --- | --- | --- | --- |
| 初级比较排序 | 冒泡、选择、插入 | `O(n²)` | 适合理解基本动作 |
| 高效比较排序 | 归并、快速、堆排序 | `O(n log n)` | 通用排序主力 |
| 分布适配排序 | 希尔排序、TimSort、Introsort | 视算法而定 | 利用局部有序或混合策略 |
| 非比较排序 | 计数、桶、基数排序 | 可接近 `O(n)` | 依赖值域或表示方式 |
| 海量数据排序 | 外部归并、多路归并 | 关注 I/O | 数据不能全部放入内存 |

## 查找与选择

- 顺序查找、二分查找、三分查找；
- 插值查找、指数查找；
- 快速选择、中位数的中位数；
- Top K、分位数和第 K 小；
- 有序集合、索引与搜索树。

::: warning 不要把二分限制在数组
只要答案空间具有单调性，就可能“二分答案”。数组有序只是最容易看见的一种单调。
:::
