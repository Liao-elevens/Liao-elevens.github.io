# 字符串算法

字符串算法研究的不只是“字符数组”，而是怎样利用文本内部的重复、前后缀、字典关系和状态转移。

## 完整目录

| 问题 | 算法或结构 |
| --- | --- |
| 单模式匹配 | 朴素匹配、Rabin–Karp、KMP、Z 函数 |
| 回文 | 中心扩展、Manacher、回文树 |
| 多模式匹配 | Trie、AC 自动机 |
| 字符串指纹 | 多项式哈希、双哈希、滚动哈希 |
| 后缀问题 | 后缀数组、LCP、后缀树、后缀自动机 |
| 字典与前缀 | Trie、压缩 Trie、基数树 |
| 字符串 DP | 编辑距离、LCS、通配符、正则匹配 |
| 压缩与编码 | Huffman、LZ 家族、BWT、游程编码 |

## 从暴力匹配开始

在长文本中寻找短模式，最直观的方法是在每个位置重新比较。KMP 等算法的本质，是利用已经比较过的信息，避免模式串退回到完全未知的状态。

::: tip 重要前置
先熟悉数组下标、前后缀、哈希和动态规划，再进入后缀结构与自动机。
:::
