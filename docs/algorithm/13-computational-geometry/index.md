# 计算几何

计算几何把图形关系转换成向量、代数和可判断的方向关系。难点通常不在公式本身，而在边界、精度与退化情况。

## 知识目录

- 点、向量、距离、角度；
- 点积、叉积、方向判断；
- 点在线段上、线段相交；
- 点在多边形内、面积与质心；
- 凸包与旋转卡壳；
- 扫描线与矩形面积并；
- 半平面交；
- 最近点对；
- 圆、切线、圆交；
- Voronoi 图与 Delaunay 三角剖分；
- 三维向量、平面与凸包。

## 通俗理解叉积

从向量 `A` 转向向量 `B`：

- 叉积为正，通常表示逆时针转；
- 叉积为负，通常表示顺时针转；
- 叉积为零，两个方向共线。

这个判断是线段相交、凸包和多边形方向的共同基础。

::: warning 精度
整数坐标应尽量使用足够大的整数类型进行叉积；浮点几何要统一误差阈值，并显式处理共线、重合和相切。
:::
