# 算法理论与可计算性

算法理论研究的不只是“怎样更快”，还研究哪些问题可能无法更快、哪些问题甚至不存在通用算法。

## 知识目录

| 领域 | 核心问题 |
| --- | --- |
| 正确性 | 怎样证明算法对所有合法输入都正确 |
| 下界 | 在特定计算模型下，任何算法至少要做多少工作 |
| 归约 | 怎样把一个问题转化为另一个问题 |
| P 与 NP | 能快速求解和能快速验证之间有什么关系 |
| NP-complete | 为什么一批困难问题可以相互转化 |
| 可计算性 | 哪些问题存在算法，哪些不存在 |
| 在线算法 | 不知道未来输入时怎样决策 |
| 参数化算法 | 把困难集中到较小参数上 |
| 近似理论 | 无法高效求最优时能保证多接近最优 |
| 通信复杂度 | 多方计算时至少需要交换多少信息 |

## 为什么初学者也值得知道

理论不是为了增加术语，而是为了建立边界意识：

- 有些慢是实现问题；
- 有些慢是算法选择问题；
- 有些问题很可能不存在已知的高效精确算法；
- 这时应该考虑限制输入、近似、随机、参数化或启发式方案。
