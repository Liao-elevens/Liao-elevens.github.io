# 数学与数论

数学算法的重点不是背公式，而是把整数、同余、组合和线性关系转化为可以高效计算的步骤。

## 知识地图

| 领域 | 主题 |
| --- | --- |
| 整除 | GCD、LCM、扩展欧几里得、裴蜀定理 |
| 素数 | 试除、埃氏筛、线性筛、Miller–Rabin |
| 同余 | 模运算、快速幂、逆元、费马与欧拉定理 |
| 方程 | 中国剩余定理、线性同余方程 |
| 计数 | 排列组合、容斥、鸽巢原理、卡特兰数 |
| 线性代数 | 矩阵快速幂、高斯消元、线性基 |
| 多项式 | FFT、NTT、卷积、生成函数 |
| 概率 | 条件概率、期望、随机变量、马尔可夫链 |
| 博弈 | Nim、SG 函数、极小化极大 |

## 实现时的共同风险

- 中间乘法先溢出，再取模已经来不及；
- JavaScript `Number` 不能精确表示所有大整数；
- C++ 与 Java 要主动选择足够大的整数类型；
- Python 整数自动扩展，但仍要分析时间和空间；
- 浮点数比较通常需要容差，不能直接依赖完全相等。
