# 高级数据结构

高级数据结构通常围绕一个目标：在大量更新和查询之间找到更好的平衡。

## 完整目录

| 问题类型 | 数据结构 |
| --- | --- |
| 动态集合合并 | 并查集、带权并查集、可撤销并查集 |
| 前缀与区间和 | 树状数组 |
| 通用区间查询与修改 | 线段树、懒标记、线段树 Beats |
| 静态区间查询 | 稀疏表、笛卡尔树、RMQ |
| 历史版本查询 | 主席树、持久化数组、持久化 Trie |
| 动态树路径 | Link-Cut Tree、Euler Tour Tree |
| 直线或函数极值 | 李超线段树、凸包技巧 |
| 多维空间查询 | KD 树、范围树、四叉树 |
| 动态有序集合 | Treap、Splay、红黑树、跳表 |
| 大规模离线查询 | 莫队、整体二分、CDQ 分治 |

## 学习前置

先掌握递归、树、二分、前缀和与复杂度。高级结构的代码往往较长，如果不清楚它维护的“不变量”，只背模板会非常脆弱。
