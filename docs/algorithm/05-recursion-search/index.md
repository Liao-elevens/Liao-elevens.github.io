# 递归、搜索与回溯

搜索算法面对的是“答案藏在许多可能性中”的问题。核心不是盲目尝试，而是设计状态、选择、终止条件、判重和剪枝。

## 知识目录

| 家族 | 主题 |
| --- | --- |
| 递归 | 基准情况、递归关系、调用栈、递归树 |
| DFS | 树与图的深度探索、连通分量、路径 |
| BFS | 层序探索、无权最短路、多源 BFS |
| 回溯 | 排列、组合、子集、棋盘、约束满足 |
| 剪枝 | 可行性剪枝、最优性剪枝、顺序优化 |
| 判重 | 访问集合、状态编码、Zobrist Hash |
| 高级搜索 | 双向 BFS、迭代加深、A*、IDA* |
| 精确覆盖 | Algorithm X、Dancing Links |

## 回溯统一骨架

```text
搜索（当前状态）：
    如果已经形成完整答案：
        记录答案
        返回

    遍历当前可以进行的选择：
        做出选择
        搜索（下一个状态）
        撤销选择
```

“撤销选择”让同一份状态可以安全地尝试下一条分支。
