## 单篇内容验收标准

- [ ] 有明确前置知识和学习目标；
- [ ] 有一个通俗生活实例；
- [ ] 有小规模手工模拟；
- [ ] 有语言无关伪代码；
- [ ] 有 Java、Python、JavaScript、C++；
- [ ] 说明四语言关键差异；
- [ ] 分析时间和空间复杂度；
- [ ] 覆盖空输入、单元素、重复值和极端值；
- [ ] 有常见错误与反例；
- [ ] 有基础、变形和综合练习；
- [ ] 文档链接与示例经过检查。

## 为什么先完成地图

如果没有全局地图，新文章很容易重复、遗漏或放错位置。先确定完整分类和依赖，再逐页深化，才能让知识库长期增长而不失控。

本页会随着内容扩展持续更新，不会把只有标题的主题标记为“完成”。
