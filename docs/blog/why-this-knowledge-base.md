# 为什么建立这座知识库

同时从零学习 Java、Python、JavaScript、C++、Go，最容易发生的事情，是把注意力全部消耗在语法差异上。

同样是向数组末尾增加元素：

- Java 可能使用 `ArrayList.add`；
- Python 使用 `list.append`；
- JavaScript 使用 `Array.push`；
- C++ 使用 `vector.push_back`。
- Go 使用 `append`。

如果只记代码，这看起来像五个知识点。但从算法角度看，它们表达的是同一个动作：

> 把新元素放到动态数组末尾。

所以，这座知识库坚持先写出语言无关的动作和伪代码，再展示五种语言。语言不是被忽略，而是被放在正确的位置上：**算法思想之后，可靠实现之前。**

## 知识库和博客的分工

正式算法文章会保持稳定，博客则允许记录不成熟的理解、踩坑和变化。某个想法经过验证后，再沉淀到知识库正文中。

这让学习过程和最终结论都能被保留，同时又不会混为一谈。
