# 关于本站

这是 Liao 的个人学习笔记，也是一座面向零基础学习者的五语言算法知识库。

## 内容原则

1. 不用复杂术语掩盖没有解释清楚的内容；
2. 不从背模板开始，先建立问题直觉；
3. 不把五种语言当成五套算法；
4. 不只给正确代码，还解释边界和常见错误；
5. 不宣称虚假的完成度，用公开矩阵记录建设状态；
6. 不让高级专题阻塞初学主线，但在完整地图中保留它们。

## 技术形态

本站内容使用 Markdown 保存，通过静态站点生成器构建，并由 GitHub Pages 发布。知识正文、版本历史和五语言代码都保留在同一个 Git 仓库中。
