# V3：Python 与 AI 应用基础

## 目标

掌握 Python AI 服务和可靠模型接入，能够把 AI 能力变成受控、可验证的产品功能。

## 代表产品

AI 学习搭子：生成计划、解释知识、出题、错题分析、流式交互和受控工具调用。

## 前置门槛

V2 达到“学习交付完成”。真实模型、外部API、密钥和付费额度仍需单独授权。

## 产物根路径

- 课程：`docs/backend/python/`、`docs/ai/`；
- 独立练习：`learning-labs/<module-id>/`；
- 产品：AI学习搭子应用与独立Python服务；
- 动画工程：独立媒体工程中的 `modules/<module-id>/`。

## 重点安全边界

- API 密钥不得进入浏览器或仓库；
- 模型输出必须校验；
- 工具调用必须由应用控制权限和执行；
- 记录成本、错误和降级。

## 排除范围

- 完整企业 RAG 平台；
- 复杂自主 Agent；
- Java 企业服务；
- 3D AI。

## 版本完成标准

- 学习交付完成：所有模块至少 Beta，AI学习搭子主流程通过；
- 教学验证完成：所有核心模块完成目标学习者迁移验证；
- 用户能独立实现一个安全的模型调用主流程；
- 能解释 Prompt、上下文、结构化输出和工具边界；
- 产品在模型失败时有明确反馈和降级；
- 核心教学模块按协议完成验证。
