# V2：前端、TypeScript 与 Node.js

## 目标

掌握现代前端和 Node.js 全栈主线，能够独立完成有用户、数据和真实业务流程的 Web 产品。

## 代表产品

人生升级系统：技能树、学习任务、经验值、打卡、项目里程碑、学习数据和成就持续迭代。

## 前置门槛

V1 达到“学习交付完成”。

## 产物根路径

- 课程：`docs/frontend/`、`docs/backend/`；
- 独立练习：`learning-labs/<module-id>/`；
- 完整产品：独立应用工程中的 `apps/level-up-os/`；
- 动画工程：独立媒体工程中的 `modules/<module-id>/`。

## 重点算法关联

数组、哈希表、栈、队列、树、图、复杂度、缓存淘汰和搜索。

## 排除范围

- 完整 Python AI 服务；
- 企业级 Java 系统；
- 复杂 RAG 与 Agent；
- 3D 专项。

## 版本完成标准

- 学习交付完成：所有模块至少 Beta，代表产品主流程通过；
- 教学验证完成：所有核心模块完成目标学习者迁移验证；
- 用户能独立完成核心 API、数据模型和错误处理；
- 产品具备一条真实端到端用户流程；
- 权限、测试、部署和故障排查有验证证据；
- 核心教学模块按协议完成验证。
