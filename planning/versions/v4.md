# V4：RAG、Agent 与多模态

## 目标

从模型 API 调用升级到有知识、工具、评估和实时交互的 AI 系统开发。

## 代表产品

AI 研究员：读取学习资料，引用原文分析薄弱点，制定训练计划并执行受控工具。

## 前置门槛

V3 达到“学习交付完成”。外部模型、存储与数据库写操作继续按安全规则单独授权。

## 产物根路径

- 课程：`docs/ai/knowledge/`、`docs/ai/agents/`、`docs/ai/realtime/`；
- 独立练习：`learning-labs/<module-id>/`；
- 产品：AI研究员应用与服务；
- 动画工程：独立媒体工程中的 `modules/<module-id>/`。

## 重点算法关联

向量、Top K、排序、图搜索、状态机、队列、缓存和相似度。

## 排除范围

- 为使用多语言而强行拆微服务；
- 无评估的“自主 Agent”；
- 3D 角色和场景。

## 版本完成标准

- 学习交付完成：所有模块至少 Beta，研究主流程和固定评估集通过；
- 教学验证完成：所有核心模块完成目标学习者迁移验证；
- 用户能区分检索错误、生成错误和工具错误；
- 回答具有可验证引用；
- Agent 有权限、终止和人工确认边界；
- 有固定测试集和回归证据；
- 核心教学模块按协议完成验证。
